*Projet personnel · conçu, développé et déployé de bout en bout · Démo : app.claireassistante.fr*

Plateforme web (et application installable) qui **reçoit les demandes 24h/24, les qualifie
automatiquement** (motif, coordonnées, niveau d'urgence) et les **transmet à un espace
professionnel sécurisé**, avec **notification automatique**.

- **Intégré l'API Anthropic (IA)** : génération des réponses + **extraction structurée** (JSON), avec validation et assainissement des sorties

- **Automatisé les notifications** par **webhook signé** (Make / n8n / Zapier)
- **PWA installable** (mode hors-ligne), **CI** (GitHub Actions) et **test de sécurité automatisé** (vérification d'absence de fuite de données entre comptes)

**Stack** : JavaScript · PWA · Node.js · Serverless (Vercel) · Supabase (PostgreSQL + Auth + RLS) · API Anthropic · Webhook (Make / n8n).
